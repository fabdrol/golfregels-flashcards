# Dark Mode (Golfbaan) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Vervang de huidige light-theme styling met een permanente dark-mode golfbaan-thema (diep bosgroen + cream + goud) door één CSS-rewrite en vier topic-kleur-updates.

**Architecture:** Pure styling-wijziging. Eén task die `src/App.css` herschrijft met CSS custom properties als kleurpalet en alle componentstijlen, en de vier topic-kleuren in `src/data/flashcards.js` bijwerkt. Geen JSX, geen hooks, geen nieuwe bestanden.

**Tech Stack:** Plain CSS met `:root` custom properties. Geen preprocessor. Geen toggle, geen `prefers-color-scheme`.

